## How to Use

**Using PNGs:** Ready to post directly to social media.

**Editing HTML templates:**
1. Open the HTML file in a browser
2. Edit the text in the HTML (date, time, cost, etc.)
3. Screenshot or re-export as PNG

### Quick Edit Checklist

- [ ] Date (currently: Tuesday, February 24th)
- [ ] Time (currently: 6:00 PM)
- [ ] Cost (currently: Free)

## Colors Used

Modern Oscilloscope palette (matches course slides):
- Background: `#1A1A1A` (grid dark)
- Grid lines: `#2A2A2A` (subtle texture)
- Primary accent: `#00FFFF` (cyan)
- Secondary accent: `#FF6600` (orange)
- Text: `#E8E8E8` (white)
- Secondary text: `#808080` (gray)

Full palette reference: `source material/modern_oscilloscope_palette.pdf`
